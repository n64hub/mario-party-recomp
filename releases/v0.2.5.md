The first release of Mario Party: Recompiled for Windows and Linux: a native PC port of the N64 game made by static recompilation. It is not an emulator and contains no game data: you need your own ROM of the USA release (a big-endian `.z64` of 32 MiB, SHA-1 `1159bd56730094bfc71be30113e1cfc8bacf34f3`). Other regions are not supported.

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**What's new since v0.2.4:** the game starts on a PC with less memory to spare. On Windows it set aside 4.5 GB at launch, almost all of it never used, and a PC that couldn't spare that much (little RAM, a small page file or none, other programs open) showed "Failed to allocate memory!" and the game never started. It now sets aside only the memory it uses, about 1 GB at the launcher. Also new: with smooth motion on, a character's parts blend between the game's frames with their own, never with another character's, and the wipe between turns on a board closes over the board's map as well as the spaces and characters, as on a console.

**Windows:** unzip `MarioPartyRecompiled-v0.2.5-windows-x64.zip` and run `MarioPartyRecompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Linux (x86-64):** extract `MarioPartyRecompiled-v0.2.5-linux-x64.tar.gz` and run `MarioPartyRecompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType; it brings its own SDL2). Pick your ROM with **Load ROM**, then **Start Game**: the ROM is stored, so the next start goes straight to the game.

**What works:** the menus, the boards and the minigames, with sound, the game's EEPROM saves kept across restarts, and keyboard and gamepad input. Up to four people play, each with a pad of their own or the keyboard (each pad its own player with no setup, or the menu's Controls, Assign players).

**Enhancements**, each an option on the settings menu with an Original value that plays as the console does:

- Faster board movement and map scrolling (General tab)
- High resolution at the window's size
- Smooth motion at the display's refresh rate, the boards' cameras and pieces blended between the game's frames
- Widescreen: each board's view and background reach the window's edges and the players' panels its corners; scenes the game draws for 4:3 only keep black at the sides, and a minigame whose stage ends short of a wide window's edges is drawn out to where it ends
- Keyboard and gamepad controls, rebindable

**Not checked yet:** long play sessions, rumble on a pad, and the Linux build on a GPU (it has been booted on Mesa's software Vulkan only). Reports are welcome on the [issues page](https://github.com/n64hub/mario-party-recomp/issues).

The [README](https://github.com/n64hub/mario-party-recomp#readme) has what works and how to build it yourself. The same game also plays in a browser, with your ROM, at [n64hub.com](https://n64hub.com/#mario-party).
