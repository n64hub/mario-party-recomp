Mario Party: Recompiled for Windows and Linux, a native PC port of the N64 game made by static recompilation. It is not an emulator and contains no game data: you need your own ROM of the USA release (a big-endian `.z64` of 32 MiB, SHA-1 `1159bd56730094bfc71be30113e1cfc8bacf34f3`). Other regions are not supported.

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**What's new since v0.2.12:** the game's rumble reaches your pad: each port with a controller now holds a Rumble Pak, where the game found none before and never rumbled. Each frame is lighter on the desktop: the game never reads back a frame it drew, so the copy of every frame into the console's memory (a second draw of it) is off, as it already was in the browser. The sound no longer drops short bursts of silence (about 22 ms, every few seconds on a busy PC): two more retraces of sound stay queued, about 33 ms more latency.

**Windows:** unzip `MarioPartyRecompiled-v0.2.13-windows-x64.zip` and run `MarioPartyRecompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Linux (x86-64):** extract `MarioPartyRecompiled-v0.2.13-linux-x64.tar.gz` and run `MarioPartyRecompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType; it brings its own SDL2). Pick your ROM with **Load ROM**, then **Start Game**: the ROM is stored, so the next start goes straight to the game.

**What works:** the menus, the boards and the minigames, with sound, the game's EEPROM saves kept across restarts, and keyboard and gamepad input. Up to four people play, each with a pad of their own or the keyboard (each pad its own player with no setup, or the menu's Controls, Assign players).

**Enhancements**, each an option on the settings menu with an Original value that plays as the console does:

- Faster board movement and map scrolling (General tab)
- High resolution at the window's size
- Smooth motion at the display's refresh rate, the boards' cameras and pieces blended between the game's frames
- Widescreen: each board's view and background reach the window's edges and the players' panels its corners; scenes the game draws for 4:3 only keep black at the sides, and a minigame whose stage ends short of a wide window's edges is drawn out to where it ends
- Keyboard and gamepad controls, rebindable

**Not checked yet:** long play sessions, rumble on a physical pad (it was played in the browser with stand-in pads), and the Linux build on a GPU (it has been booted on Mesa's software Vulkan only). Reports are welcome on the [issues page](https://github.com/n64hub/mario-party-recomp/issues).

The [README](https://github.com/n64hub/mario-party-recomp#readme) has what works and how to build it yourself. The same game also plays in a browser, with your ROM, at [n64hub.com](https://n64hub.com/#mario-party).
